# CV público de Johnny Nicolaz

Sitio estático del currículum profesional de Johnny Nicolaz, preparado para GitHub Pages.

## Fuente de verdad

`index.html` es el documento que se valida y publica. No se debe editar directamente desde GitHub sin trasladar después el mismo cambio a esta carpeta local.

## Indicadores del dashboard

Los indicadores se derivan únicamente del CV revisado:

- `15+` años de trayectoria declarada;
- `7` experiencias profesionales con empresa y fechas;
- `4` ámbitos: seguros, inmobiliario, microfinanzas y presupuesto público;
- `2` titulaciones superiores: Economía y MBA.

La distribución del gráfico cuenta puestos documentados: seguros `3`, inmobiliario `2`, microfinanzas `1` y presupuesto público `1`. No representa resultados de negocio ni métricas de ventas.

## Privacidad

La versión pública incluye nombre, localidad, teléfono, correo, experiencia y formación. No incluye la dirección postal completa ni métricas inventadas.

## Publicación

Configuración prevista para GitHub Pages:

- repositorio: `proselcommalaga/johnny-nicolaz-cv`;
- rama: `main`;
- origen de Pages: raíz de la rama;
- URL prevista: `https://proselcommalaga.github.io/johnny-nicolaz-cv/`.

Antes de publicar o actualizar se debe completar `QA.md` y comprobar la URL pública, no solo la vista local.
